# 🛠️ Engineering Toolbox

A Python-based Engineering Toolbox built with **Tkinter**. This project provides a simple graphical interface for engineering calculations and unit conversions.

## ✨ Features

- 📏 Length Converter
- 📐 Geometric calculations
- 🔺 Triangle validity checking
- 🖥️ User-friendly graphical interface
- ✅ Input validation and error handling

## 🧰 Technologies Used

- Python
- Tkinter
- Visual Studio Code (for development)

## 🚀 How to Run

1. Install Python from [python.org](https://www.python.org/downloads/).
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the main Python file:

   ```bash
   python main.py
   ```

   Replace `main.py` with the actual name of your main Python file if it is different.
